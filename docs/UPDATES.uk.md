# Оновлення OneAIWorkers

[English version](UPDATES.md)

Кожен встановлений OneAIWorkers має власну сторінку оновлення:

```text
https://ВАШ-WORKER.ВАШ-ПІДДОМЕН.workers.dev/update
```

## Що бачить користувач

OneAIWorkers перевіряє наявність оновлень під час використання MCP-інструмента. Якщо є нова версія, відповідь спочатку показує пряме посилання на оновлення, а вже потім звичайний результат.

Відкрийте це посилання у звичайному браузері. Не викликайте його через `fetch_url` або інший серверний інструмент. Серверний запит може повернути помилку, навіть якщо сторінка правильно працює у браузері користувача.

MCP не може показати повідомлення, поки клієнт не звертається до Worker. Успішна перевірка оновлення може зберігатися в пам’яті до шести годин.

## Як оновити

1. Відкрийте посилання `/update` у звичайному браузері.
2. Увійдіть у Cloudflare.
3. Виберіть обліковий запис, якому належить Worker.
4. Підтвердьте оновлення.
5. Поверніться до чату. Стабільний живий шлюз працює без перепідключення. Оновіть список лише якщо хочете побачити нові короткі окремі команди.

Служба оновлення перевіряє через Cloudflare, що Worker належить вибраному обліковому запису. Вона замінює лише код Worker. Дані D1, налаштування конекторів, прив’язки та Cloudflare Secrets зберігаються.

Посилання на оновлення не містить ключів, токенів або секретів.

## Офіційне джерело оновлень

За замовчуванням Worker перевіряє:

```text
https://raw.githubusercontent.com/maslybs/OneAIWorkers/main/update-manifest.json
```

Якщо цей файл недоступний, звичайні MCP-інструменти продовжують працювати. Власник проєкту може змінити джерело через `UPDATE_MANIFEST_URL` або вимкнути перевірку через `UPDATE_CHECK_ENABLED=false`.

Для кожної версії GitHub автоматично публікує незмінну збірку `oneaiworkers-worker.mjs`, її опис і контрольну суму SHA-256. Центральний встановлювач не містить копії OneAIWorkers. Після дозволу користувача він завантажує випуск, що відповідає `latest_version`, перевіряє його і лише тоді передає код у Cloudflare користувача.

Після зміни OneAIWorkers не потрібно перезбирати встановлювач. Збільште версію в `package.json`, `APP_VERSION` та `update-manifest.json`, а потім надішліть зміни в `main`. GitHub запустить перевірки й опублікує відповідну збірку. Уже опублікована версія ніколи не замінюється.
