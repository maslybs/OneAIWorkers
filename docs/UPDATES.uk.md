# Оновлення OneAIWorkers

Кожен встановлений OneAIWorkers має власну сторінку оновлення:

```text
https://АДРЕСА-ВАШОГО-WORKER/update
```

Якщо офіційний опис версії містить новішу версію, OneAIWorkers додає до результатів MCP:

- поточну версію;
- нову версію;
- ознаку важливого оновлення;
- посилання на `/update` цього самого Worker.

Тому ChatGPT або інший MCP-клієнт може повідомити користувачу про оновлення під час звичайної роботи.

MCP не може показати повідомлення, коли клієнт не звертається до Worker. Перевірка відбувається під час виклику інструмента або відкриття сторінки `/update`.

## Безпека

Посилання на сторінку оновлення не містить ключів, токенів або секретів.

Сторінка `/update` працює на Worker користувача. Кнопка входу зʼявляється лише тоді, коли в офіційному описі версії або в налаштуванні Worker є адреса служби авторизації.

Після натискання користувач має увійти безпосередньо в Cloudflare і підтвердити дозвіл. Служба оновлення повинна повторно перевірити через Cloudflare, що вибраний Worker належить цьому користувачу.

Вбудована служба з [`installer/`](../installer/) робить цю перевірку для адрес `workers.dev`. Вона також вимагає наявність привʼязок `OAUTH_DB` і `MCP_SHARED_SECRET`. Оновлення успадковує всі наявні привʼязки в Cloudflare, тому значення секретів не читаються і не передаються встановлювачу.

## Офіційний опис версії

За замовчуванням Worker перевіряє:

```text
https://raw.githubusercontent.com/maslybs/OneAIWorkers/main/update-manifest.json
```

Невдале отримання опису не блокує MCP-інструменти. Помилка перевірки версії кешується на пʼять хвилин, успішний результат — на шість годин.

Доступні опційні налаштування:

```text
UPDATE_CHECK_ENABLED=false
UPDATE_MANIFEST_URL=https://example.com/update-manifest.json
UPDATE_SERVICE_URL=https://example.com/start
```

`UPDATE_SERVICE_URL` задає власник проєкту після розгортання центрального встановлювача. Звичайні користувачі не повинні налаштовувати його вручну.
