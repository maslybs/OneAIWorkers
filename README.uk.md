# OneAIWorkers

[English version](README.md)

OneAIWorkers — це приватний MCP-шлюз для ChatGPT, Claude та інших MCP-сумісних клієнтів. Він працює у вашому Cloudflare, зберігає ключі сервісів у зашифрованому вигляді у вашій D1 і розширюється через плагіни.

```text
ChatGPT / Claude / інший MCP-клієнт → OneAIWorkers → встановлені плагіни та сервіси
```

Простий встановлювач створює Worker, базу D1, прив’язку Workers AI, сховище агентів, приватний секрет доступу та ключ шифрування. На останній сторінці він показує захищену адресу `/mcp` і секрет. Одразу збережіть секрет: його показують лише один раз.

## Підключення клієнта

Для всіх підтримуваних клієнтів використовується одна адреса:

```text
Авторизація: OAuth
Адреса сервера: https://ВАШ-WORKER.ВАШ-ПІДДОМЕН.workers.dev/mcp
```

- У ChatGPT додайте власний MCP-застосунок і виберіть OAuth.
- У Claude додайте власний віддалений MCP-сервер. Необов’язкові поля Client ID і Client Secret залиште порожніми.
- Інші клієнти можуть працювати через Streamable HTTP та OAuth. Клієнт без OAuth може передати секрет у заголовку `Authorization: Bearer`.

Коли відкриється сторінка входу OneAIWorkers, введіть секрет доступу. Ніколи не додавайте його до адреси.

Приклади є у розділі [підключення клієнтів](docs/CLIENTS.uk.md).

## Як це працює

У публічному MCP завжди є рівно шість команд:

```text
w_search
w_describe
w_call
w_present
w_result_read
w_agent_run
```

Встановлення або оновлення плагіна не змінює цей список. Тому ChatGPT і Claude не тримають застарілі списки дій.

1. `w_search` шукає дозволені дії за текстом і змістом.
2. `w_describe` завантажує точні схеми лише для вибраних дій.
3. `w_call` перевіряє та виконує одну незмінну дію.
4. `w_present` створює візуальний результат.
5. `w_result_read` дочитує малу частину великого результату.
6. `w_agent_run` запускає дозволеного агента або команду з обмеженнями.

Права перевіряються до пошуку і ще раз перед виконанням. Для ризикової дії користувач має відкрити захищене посилання у браузері. Одноразове схвалення прив’язане до користувача, дії та незмінених даних. Агент не може схвалити свою дію сам.

## Додавання плагіна

Напишіть MCP-клієнту, який сервіс або результат вам потрібен:

```text
Знайди плагін для перегляду процесів n8n і невдалих запусків.
```

OneAIWorkers шукає у каталозі всередині вашого Worker. Якщо сумісний хмарний плагін існує, відповідь починається з точного посилання для встановлення.

1. Відкрийте посилання у звичайному браузері.
2. Підтвердьте встановлення у Cloudflare.
3. Введіть адресу сервісу та ключ лише на сторінці власного OneAIWorkers.
4. Поверніться до чату. `w_search` одразу знайде новий плагін. Перепідключати MCP-клієнт не потрібно.

Ключ сервісу не потрапляє до каталогу або центрального встановлювача. OneAIWorkers шифрує його через `CREDENTIALS_MASTER_KEY` перед записом у D1.

## Пакунки плагінів

Основний формат пакунка — `oneai.plugin.v1`. Один пакунок може містити хмарні дії, виконувані навички, агентів, підказки, ресурси, частини інтерфейсу, налаштування, права та код.

Кожна доступна для виклику дія має незмінне посилання:

```text
<plugin_id>:<capability_id>/<method>@<version>
```

Виконувана навичка потребує формального опису `oneai.skill-api.v1` із точкою входу, методами, схемами, правами та описом побічних дій. Звичайний `SKILL.md` лишається інструкцією і не може запускати код.

Докладніше: [W Gateway і пакунки плагінів](docs/W_GATEWAY.uk.md).

## Безпека

- Самої адреси Worker недостатньо для доступу до MCP.
- `/mcp` захищений через OAuth і `MCP_SHARED_SECRET`.
- Ключі сервісів не потрапляють до пошуку, векторів, журналів або стислих результатів.
- `w_call` не приймає довільну адресу або довільний метод запиту.
- Великі результати зберігаються у D1 або R2 і читаються малими дозволеними частинами.
- Команди публікації доступні лише через `/mcp/admin` і лише адміністратору.

Докладніше: [безпека](docs/SECURITY.uk.md).

## Оновлення

Коли з’явиться оновлення, відкрийте у звичайному браузері:

```text
https://ВАШ-WORKER.ВАШ-ПІДДОМЕН.workers.dev/update
```

Оновлювач замінює код Worker, але зберігає D1, встановлені плагіни, налаштування та секрети Cloudflare. Докладніше: [оновлення](docs/UPDATES.uk.md).
